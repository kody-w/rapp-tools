RAPP Tools

Four independent native macOS applications. This repository provides their shared build and discovery infrastructure, not a fifth app.
Native apps, local processing. Download for Apple silicon or Intel, unzip in Finder, and move the app to Applications. The released apps are Developer ID-signed, notarized and stapled. They require macOS 14 or newer, not Homebrew, Python, Hammerspoon, a terminal or a separate Brainstem.

Speech models download only after first-run setup. Capture and input permissions remain under your control; optional cloud processing requires explicit consent.

Browse RAPP Store. Each source repository holds its own versioned downloads and immutable verification evidence.
