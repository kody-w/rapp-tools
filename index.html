RAPP Tools

One catalogue for local-first RAPP tools. Every entry is a hatchable rapplication: it boots into its own brainstem on its own port and is driven headlessly over /chat, with a UI as an option rather than a requirement.
Headless first, UI optional. Every tool below hatches into its own brainstem on its own port and is driven over the same /chat contract — so an agent, a script, or a person can use it. Each ships a UI, but nothing requires one.

Nothing is vendored here. Entries point at each tool's own repository, so the tool's repo stays the source of truth.
